# Review-Insight-Extractor
Review Insight Extractor

## Data acquisition

The project uses the official Amazon Reviews 2023 All Beauty review data from Hugging Face:

- Source: https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023
- Exact reviewed revision used for the full review Parquet download:
  100524046db2ba65a5deb76ac87af7fdd8769f11
- Full review parquet URL:
  https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023/resolve/100524046db2ba65a5deb76ac87af7fdd8769f11/raw_review_All_Beauty/full-00000-of-00001.parquet
- Local project path: data/raw/all_beauty_reviews_full.parquet

This file is intentionally kept local and ignored by Git via .gitignore because it is a large dataset snapshot, not a source file to commit. The 500-record sample remains in data/raw/all_beauty_sample_500.csv and is not regenerated by the full-data download.

Expected storage requirement for the full source review file: roughly 130-140 MB for the current revision, with the sample CSV adding only a few hundred KB.

## Notes

- The project did not contain an existing notebook or loader script when Stage 1 began.
- The dataset source was verified before downloading.
- The sample CSV uses a fixed seed and a deterministic review identifier derived from original source fields; it is not a row-number substitute.
